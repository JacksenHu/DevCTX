# 项目文档索引（单一事实源）

> **新建任何文档前，必须先查本文件。** 能并进现有文档的，禁止新建。
> **一个需求只对应一份文档**，按主题组织，严禁按对话轮次组织（"登录-第2次.md" 是反模式）。
> 用户中途插话 / 输出后追加要求 / 发现理解错了 → 都是**修改现有文档**，不是新建。

| 文档 | 主题 | 状态 | 来源需求 | 最近更新 | 关联记录数 |
|---|---|---|---|---|---|

## 怎么用本文件

1. **动手前**：跑 `scripts/doc_registry.py <根> --find <关键词>` 或直接读本文件，确认这个需求有没有主。
2. **有主** → 打开那份文档，在「需求变更」里追加，**不要建新文件**。
3. **没主** → 才新建 `docs/<领域>-<主题>.md`（照 `docs/0000-template.md`），并立刻登记进本文件。
4. **文档爆掉**（超过两屏）→ 拆成同主题子文档，在本文件互相引用，仍然一个需求一条线。
5. **已闭环** → 状态改 `stable`；确认废弃 → `--archive` 归档，别堆在目录里。
