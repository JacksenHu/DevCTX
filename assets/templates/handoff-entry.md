# 对话压缩记录

> 每轮对话结束（AI 输出回复之后）追加一条，**只增不改**。
> 文件名：`<时间戳>-<Agent>-<会话Id>.md`，例 `20261012-162033-claude-code-a1b2c3d4.md`。
> 有 devctx 技能时由 AI 调用 `scripts/log_handoff.py` 生成；没有时照本模板手工写，
> 写完后运行一次 `--rebuild-index`（或手工同步 `INDEX.md` 的一行）。

## 用户原话

> 用户这一轮的**完整原始需求**，一字不删、不改写、不概括。
> 换 Agent / 换模型后，靠这段还原"到底要做什么"，而不是靠猜。

## 本轮压缩

> 五个小节**可缺省、可任意组合**，但至少要有一个。
> 判断标准：下一个模型不知道它，会不会走错路或重复劳动？

### Done

- 已经做了什么，具体到可验证结果（改了哪个文件、跑到什么状态）

### Next

- [ ] 下一步做什么，按依赖排序；完成即勾选

### Verify

- 要跑什么测试 / 命令来证明上面的 Done 真的成立

### Risks

- 有什么坑：试过且走不通的路、容易踩的雷、需要避开的事项
